# 诡秘之主：廷根异闻

OC AU 单机大世界沙盒，八段长线旅程：从廷根、贝克兰德、海上、南大陆、战争、神弃之地、末日，一直走到源堡。

**在线试玩：** <https://executor0707.github.io/tingen-oc-au/>

> 非官方、非商业同人。原作权利归爱潜水的乌贼及相关权利方所有。线上构建不含原作长段正文。

## 现在可以玩什么

- 捏一个原创非凡者：出身、途径、序列 9 起点、缺陷、初始人脉、外观
- 八段地图：廷根、贝克兰德、海上、南大陆、战争、神弃之地、末日、源堡
- **915 天长线日历**：廷根 120 天 → 贝克兰德 180 天 → 海上 180 天 → 南大陆 120 天 → 战争 120 天 → 神弃之地 90 天 → 末日 60 天 → 源堡 45 天
- 每天 **5 个行动点**：上午 2 + 下午 3
- **微养成**：上课/自学、打工、训练、社交，提升属性，也可能认识次要 NPC
- **长期委托**：接取后直接跳过 7 / 15 天，结算属性、英镑和序列材料；期间每日有概率触发“意外之喜”
- **每日报纸**：canon 行踪、玩家影响、市井传闻
- **50 个可玩 canon 锚点**：旁观、接触或介入，改写后续报纸与结局
- **序列晋升**：扮演、购买/寻找主材料、成功率判定；失败会消耗材料并增加疯狂/伤害
- **身份线索**：在不同时间地点逐渐意识到克莱恩的多个身份
- **高序列灰雾事件**：序列降至 4 以下后，可能被拉入灰雾，获得原作没有的「空白卡牌」
- **68 个结局**：普通人的生活、核心结局、坏结局和零散隐藏结局
- 档案库：结局档案、110 个八部 canon 总表、29 个人物档案
- 自动档 + 3 个手动档；导出/导入 JSON
- **黑夜 / 白昼主题**；默认整体 UI 125%，设置中可切换 100% / 125% / 140%

## 运行

```powershell
python -m http.server 4180 --directory build/app
```

打开 <http://127.0.0.1:4180/>。

Pages 构建：

```powershell
python -m http.server 4181 --directory build/pages
```

## 数据

- `build/app/data/world/canon_events.js`：110 个 canon 锚点
- `build/app/data/world/game_data.js`：廷根出身/途径/地点/委托/事件/结局
- 其余 `*_data.js`：贝克兰德、海上、南大陆、战争、神弃之地、末日、源堡
- `design/CANON_EVENTS.md`：可读的事件表
- `design/ENDINGS.md`：结局矩阵
- `PRODUCT_BRIEF.md`：产品边界

## QA
